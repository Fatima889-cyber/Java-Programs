# Java Programs

A collection of Java practice programs developed to learn and practice Core Java and Object-Oriented Programming (OOP) concepts.

## Topics Covered

- Core Java Basics
- Variables and Data Types
- Conditional Statements
- Loops
- Arrays and 2D Arrays
- ArrayList
- Methods
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Method Overloading
- Method Overriding
- Exception Handling
- File Handling
- Comparable Interface
- Matrix Addition
- Mini Projects

## Language

- Java

## Purpose

This repository is created for learning, practicing, and improving Java programming skills.
